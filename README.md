# Qualitiative Data Analysis with LLMs

This repository contains supplementary material for DK UK's webinar on 'AI and analysis: Can you use AI on qualitative data?'

## Fetching Raw Data

We are working with the pxtextmining data, which was generated by the NHS from the [Care Opinion API](https://www.careopinion.org.uk/info/api-v2) and is distributed through their [pxtextiming repository](https://github.com/The-Strategy-Unit/pxtextmining/tree/main/datasets/phase_1).

You can download the data manually from the link above or if you are a commandline user, you can run 

```
curl -O https://raw.githubusercontent.com/The-Strategy-Unit/pxtextmining/main/datasets/phase_1/text_data.csv
```
