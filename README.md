# Qualitiative Data Analysis with LLMs

This repository contains supplementary material for DK UK's webinar on 'AI and analysis: Can you use AI on qualitative data?'

## Fetching and Preparing Raw Data

We are working with the pxtextmining data, which was generated by the NHS from the [Care Opinion API](https://www.careopinion.org.uk/info/api-v2) and is distributed through their [pxtextiming repository](https://github.com/The-Strategy-Unit/pxtextmining/tree/main/datasets/phase_1).

### Fetching the Raw Data
You can download the data manually from the link above or if you are a commandline user, you can run 

```
curl -O https://raw.githubusercontent.com/The-Strategy-Unit/pxtextmining/main/datasets/phase_1/text_data.csv
```

Once the data is downloaded, add it to the data/raw folder. 

### Visualizing the Raw Data Taxonomy

To create a vizualization of the raw data taxonomy, run 
```
uv run python -m scripts.plot_label_distribution
```

By default this plots `data/raw/text_data.csv` and saves the figure to `artifacts/taxonomy.png`. To plot a different file (e.g. a subsample) or save elsewhere, pass `--data-path` and/or `--target-path`:
```
uv run python -m scripts.plot_label_distribution --data-path data/interim/text_data_subsampled_20.csv --target-path artifacts/taxonomy_subsample_20.png
```

### Subsampling Raw Data
The raw data contains a little over 10.000 rows. To create a smaller subset, you can run
```
uv run subsample_data.py <number_of_desired_rows>
```
